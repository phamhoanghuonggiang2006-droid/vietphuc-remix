## 📖 Giới thiệu Dự án

**HeritStyle AI** là một Fashion Pair-Stylist thông minh, đóng vai trò như một người bạn đồng hành về thời trang cho thế hệ trẻ (Gen Z). Dự án giải quyết bài toán: **Làm sao để người trẻ tự tin diện Cổ Phục (Áo Ngũ Thân, Áo Tấc, Áo Nhật Bình) vào đời sống hàng ngày mà không sợ bị "lệch chuẩn" hay phạm vào các quy tắc cấm kỵ văn hóa lịch sử?**

Dựa trên nguồn tư liệu chuẩn mực từ *Khâm Định Đại Nam Hội Điển Sự Lệ* kết hợp cùng công nghệ Trí tuệ Nhân tạo từ **Google AI Studio (Gemini Flash)**, HeritStyle AI phân luồng trang phục thông minh, chấm điểm phong cách (Slay Score) lẫn độ chuẩn mực di sản (Heritage Score), đồng thời cung cấp kiến thức văn hóa ngầm thông qua cơ chế Gắn Nhãn (Smart Naming).

## ✨ Các Tính Năng Nổi Bật

### 1. 🎛️ Ma Trận Phân Luồng 3 Mode (3-Tier Engine)
* **Mode 1 — Chốn Tôn Nghiêm (Heritage Core):** Phối đồ chuẩn mực nghi thức (Đại lễ phục, gia tiên, đền chùa). Xuất bản phẩm **Tạp chí Editorial Vogue Cung Đình**.
* **Mode 2 — Thanh Lịch Đời Thường (Modern Heritage):** Phối cổ phục cùng trang phục thường nhật thanh lịch (quần tây, chân váy xếp ly, loafer da, túi tote).
* **Mode 3 — Phố Thị Phá Cách (Fusion Streetwear):** Layering độc bản phong cách Hypebeast, Acubi, Cyberpunk Á Đông (quần cargo túi hộp, chunky sneaker, phụ kiện xích bạc).

### 2. 🧠 Bộ Não Stylist Custom Gem (Google AI Studio)
* Tích hợp trực tiếp **Google AI Studio Gemini API** với Custom System Prompt chuyên sâu.
* Nhận diện và thẩm định độc bản từng cặp phối chi tiết: *Áo ngoài $\times$ Sắc phục $\times$ Thân dưới $\times$ Giày guốc $\times$ Khuy cúc $\times$ Đơn y $\times$ Đa phụ kiện*.
* Cơ chế **Dynamic Combinatorial Engine** cục bộ giúp tính toán và đưa ra nhận xét tức thì thời gian thực.

### 3. 🛡️ Bộ Lọc Cấm Kỵ Điển Chế (Taboos Filter 3 Mức Độ)
* **Mức Đỏ (Red Alert):** Phát hiện các lỗi xâm lấn văn hóa hoặc sai lệch quy thức (Cúc vải tết dây/cúc tàu Mãn Thanh, Vàng hoàng chính sắc của Thiên tử, Nhật Bình nữ đội Khăn Đóng nam, bỏ áo đơn y ở chốn tôn nghiêm). Cảnh báo và yêu cầu chuẩn hóa.
* **Mức Vàng (Yellow Alert):** Xung đột bối cảnh (mang giày thể thao/quần túi hộp đi đền chùa) $\rightarrow$ Tự động chuyển đổi thẻ nhãn sang *"Lấy cảm hứng (Heritage Inspired)"*.
* **Mức Xanh (Info):** Khen ngợi và phân tích thần thái phong cách (Tet-Core, Quiet Luxury, Neo-Trad).

### 4. 📜 Xuất Hồ Sơ Y Phục & LookBook Tạp Chí Siêu Nét
* Xuất file **Poster / LookBook HD** với đầy đủ: Manocanh đa phụ kiện chuẩn tỷ lệ Canvas, Bảng phân tích Ngũ Thường & Ngũ Hành, Bảng mã màu Pantone sắc phục, và Chứng chỉ Thẩm định Stylist.

## 🚀 Hướng Dẫn Cài Đặt & Chạy Cục Bộ (Local Setup)

```bash
# 1. Clone repository về máy
git clone https://github.com/phamhoanghuonggiang2006-droid/vietphuc-remix.git

# 2. Di chuyển vào thư mục dự án
cd vietphuc-remix

# 3. Cài đặt các thư viện phụ thuộc
npm install

# 4. Khởi chạy môi trường phát triển (Dev Server)
npm run dev
```

Mở trình duyệt tại: `http://localhost:3000`
